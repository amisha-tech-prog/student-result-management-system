Student Result Management System

Project Overview

The Student Result Management System is a web application developed using Python and Django to manage student details and academic results.

Features

- Student Login
- Student Details Management
- Student Result Management
- Database Integration
- User-Friendly Interface

Technologies Used

- Python
- Django
- HTML
- CSS
- SQLite

Installation and Setup

1. Clone the Repository

git clone https://github.com/amisha-tech-prog/student-result-management-system.git

2. Open the Project Folder

cd student-result-management-system

3. Install Django

pip install django

4. Run Database Migrations

python manage.py migrate

5. Start the Server

python manage.py runserver

Open "http://127.0.0.1:8000/" in your browser.
